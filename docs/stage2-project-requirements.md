# Stage 2 – Project Requirements & Development Plan

## 1. Functional Requirements

- The system shall accept room temperature as input.
- The system shall accept the number of occupants.
- The system shall accept a target temperature.
- The system shall decide whether the HVAC should be ON or OFF.
- The HVAC shall turn ON when the room is above the target temperature and occupancy is greater than zero.
- The system shall display the current system status.
- The system shall provide a Linux-based interface for future device-level integration.
- The system shall handle invalid inputs safely.

## 2. Non-Functional Requirements

- The project shall run on Linux.
- The implementation shall use C++.
- The code shall be modular and maintainable.
- The system shall provide clear and readable output.
- The system shall handle errors safely.
- The project shall include testing and documentation.

## 3. Project Modules

1. Temperature Simulation Module
2. Occupancy Simulation Module

4. Linux Device Interface Module

## 4. Project Features
